# Monkey Launch live config

Every copy of Monkey Launch reads `config.json` from this repo when it starts, and every 10 minutes on the main menu. Edit it with the Admin Panel in the Unity editor (**Monkey Launch > Admin Panel**).

The file controls the news message, maintenance mode, XP boosts, gifts, the featured mode, bans, the newest version and the oldest version still allowed.

This repo is public so the game can read it without signing in. Never put secrets here. Desktop update zips go in this repo's Releases.
